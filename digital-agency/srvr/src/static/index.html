Digital Agency API

Добро пожаловать в API сервер Digital Agency. Это backend-сервис для приложения Digital Agency.

Статус сервера: Онлайн

API Endpoints

/health - Проверка состояния системы /metrics - Метрики Prometheus /metrics/uptime - Процент доступности системы

Мониторинг системы

Система мониторинга отслеживает следующие параметры:

  • Подключение к базе данных
  • Использование памяти
  • Дисковое пространство
  • Время отклика API

Для просмотра панели мониторинга, войдите в систему как администратор и перейдите в раздел "Мониторинг".
